# GP-Combine 展示站

GP-Combine 固件（基于 GP2040-CE 的双芯格斗手柄固件）的彩色屏幕菜单图鉴。

## 内容

- **滑动菜单**：7 个页面（设置 / 电池 / 灯光 / 背景 / 休眠 / 无线 / 小游戏）及其全部选项列表
- **动态壁纸**：GIF 作主界面背景
- 两套分辨率可切换：`240 × 135`（横屏版）与 `170 × 320`（竖屏版）
- 深链：`?res=240` / `?res=320`

### 动画素材（`assets/<res>/anim/`）

| 文件 | 内容 | 体积 |
|---|---|---|
| `page_slide.webp` | 按 ← → 切页的整屏横滑（280ms 缓出 + 尾部停顿便于循环） | ~10 KB |
| `wallpaper.webp` | 动态壁纸的完整 60 帧 / 3 秒循环（20fps） | 523 KB / 794 KB |

都是**动画 WebP**（真彩、`<img>` 直接播），不是 GIF 也不是视频。用**无损**编码：
16 色调色板的像素画无损反而比有损更小，而且不会有压缩伪影。

## 部署（GitHub Pages）

纯静态、无构建步骤。任选一种：

1. **独立仓库（推荐）**：新建仓库 → 把本目录内容推到 `main` → Settings → Pages → Source 选 `Deploy from a branch` / `main` / `/ (root)`
2. **gh-pages 分支**：推到主仓库的 `gh-pages` 分支

注意主仓库 `.git` 已 300MB+，**不要把本站放进主仓库靠 Pages 构建**，会拖慢甚至失败。

## 截图是怎么来的

`assets/` 下的图片**不是截图工具抓的，也不是重画的**，是固件渲染层在电脑上跑出来的真实画面：

1. 用 `arduino-cli` 编译两份固件（`esp32` / `esp32_170x320`），拿到带自动函数原型的 `sketch/*.ino.cpp`
2. 宿主机用最小平台垫片（Arduino / SPI / LittleFS / FreeRTOS / ESP-IDF SPI）编译同一份源码，
   把 `lfb[]`（整屏 RGB565 帧缓冲）按确定性假时钟逐帧导出
3. 脚本化按键时间轴走固件真实的 UART 输入帧解析路径（19 字节 INPUT 帧 + CRC16），
   于是长按 S2、翻页、进子页、返回全是固件自己的状态机

因为 `.ino` 源码零改动，**页面里看到的菜单行为与真机一致**（包括状态栏文案、页面指示器位置）。

## 加图 / 换图

图片按名字引用，命名来自仿真器的巡演脚本：

```
assets/240/*.png   240×135  15 张
assets/320/*.png   170×320  17 张
home_wallpaper      主界面（动态壁纸）
page_01..07_<名字>  各页封面
opt_<分区>          各页的选项列表
setting_sections    设置页的分区选择
nes_list            小游戏 ROM 列表
```

要增删，改 `app.js` 顶部的 `SHOTS` 配置即可，不用动 HTML/CSS。
